# etolegko-tst

Скрипт измеряет скорость скачивания по URL: десять последовательных GET-запросов с полным чтением тела ответа.

## Запуск

```bash
node src/measure.js <URL>
```

Пример:

```bash
node src/measure.js https://example.com/large-file.bin
```

Без аргумента URL процесс завершится с ненулевым кодом выхода.

Проверка тестов:

```bash
npm test
```

## Единицы

- **Скорость в консоли** — килобайты в секунду (**KB/s**): `speedKBps = (totalBytes / 1024) / totalSeconds`, где `totalSeconds` — суммарное время всех десяти запросов.
- **`averageRequestSeconds`** — среднее время одного запроса (от старта до полного получения тела), в секундах.
- **`totalBytes`** — суммарный объём скачанных данных по всем ответам, в байтах.

Kibibyte-based KB/s (1024 байта = 1 KB).
